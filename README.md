# TsukiRe Web — веб-порт ремейка Tsukihime

Играбельный веб-плеер «Tsukihime - A piece of blue glass moon»
(Switch-версия) на чистом HTML/CSS/JS, без шага сборки.
Семантика движка воспроизведена по реимплементации
[knife](https://github.com/AuroraWright/knife): скрипты сцен,
моции, градации, переходы, бэклог, сейвы, флоучарт, галерея
(CG, музыка, фильмы, эндинги).

- Языки: японский, английский, китайский упрощённый и традиционный.
- Рендер: WebGPU с автоматическим откатом на Canvas2D.
- Номер сборки виден в углу экрана плеера (метка BUILD).

## Быстрый старт (локально)

1. Рядом с кодом должны лежать media: `assets/`, `scenes/`,
   `data/*.webp` (см. [LAYOUT.md](LAYOUT.md)). Локально это могут
   быть симлинки на распаковку `dist/`.
2. Запустить статический сервер из корня кода
   (`file://` не подойдёт: плеер грузит сцены через `fetch`):
   `python3 -m http.server 8000`
3. Открыть `http://localhost:8000`.

Без `media-base.json` всё работает относительными путями.
С заданным `media-base.json` (`{"base": "https://media..."}`)
картинки, аудио, видео и сцены тянутся с media-домена,
а кодовые файлы (`manifest.json`, `data/*.json`, шрифты) —
по-прежнему с кодового.

## Раскладка

Этот репозиторий — только код:

- `index.html`, `style.css`, `js/` — плеер;
- `data/*.json` — таблицы движка (картинки, моции, градации,
  флоучарт, галерея, петли BGM, тексты интерфейса);
- `fonts/` — шрифт окна сообщений;
- `manifest.json` — настоящий манифест сцен (не симлинк);
- `deploy/` — nginx-конфиг, скрипт обновления, шаблон
  `media-base.json`;
- `CHANGELOG.md` — история сборок;
- `LAYOUT.md` — подробная раскладка: что в git, что на media,
  что такое `media-base.json`, шаги деплоя.

Media в репозиторий не входит и отдельно не распространяется:
`assets/` (img, bgm, se, voice, movie), `scenes/` (549 JSON),
`data/*.webp` (UI-текстуры) живут на media-домене зеркалом
структуры запросов. `media-base.json` в корне кода на сервере
создаётся один раз из `deploy/media-base.json` и в git не входит.

## Деплой

Коротко: код — в корень сайта (`git clone` в `/var/www/tsuki-re/code`),
media — в корень media-домена, `media-base.json` — один раз
из `deploy/`, nginx — по `deploy/nginx-tsukiweb.conf`,
обновления — через `deploy/update.sh` (`git pull` только кода,
media не трогает). Подробно — в [LAYOUT.md](LAYOUT.md),
раздел «Деплой по шагам».

## Управление

- Клик / Space — дальше по тексту.
- Esc / правая кнопка мыши — меню / на уровень назад.
- X — бэклог, A — авто-режим, Ctrl (удерживать) — скип.
- Верхняя шторка мыши — панель режимов (назад, авто, ускорение,
  скип, быстрое сохранение/загрузка, звук).
- Геймпад поддерживается (раскладка по knife: A — дальше,
  B — отмена, Y — меню, R — скип, L — авто, X — бэклог,
  ZR — ускорение, стики — навигация).
- Сохранения хранятся локально в браузере (IndexedDB +
  localStorage), есть экспорт/импорт в экране сейвов.

## Известные пробелы

- Бегущий текст титров staff roll не рисуется: он на стороне
  exe, knife его тоже не рисует.
- Иконки-bubble и оригинальные текстуры диалогов SELA/SELS
  не воспроизведены (только визуально).
- Голосовые строки конфига зависят от услышанных в игре голосов.

Подробная история изменений — в [CHANGELOG.md](CHANGELOG.md).
